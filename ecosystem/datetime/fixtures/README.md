# Timezone fixture provenance

The six IANA TZif files are unmodified distribution data from tzdata `2026c` (`VERSION`), retained with SHA-256 hashes in `SHA256SUMS`. The database is public-domain data: https://data.iana.org/time-zones/tz-link.html. The GoML consumer test checks every listed hash before accepting these fixtures.

`Synthetic/` holds deliberately authored raw TZif fixtures defined by RFC 9636. They were generated by the historical `fixture_builder.py` at repository revision `27f8b1649561504bbe61d5247500e7cadc6eef42`. The fixtures are retained directly, and the native `../tests/fixture_layout_test.gom` test independently constructs every byte again using RFC 9636 headers, counts, offsets, transition indexes, names and footers. This preserves the complete generation recipe without using the datetime implementation or a Python runtime. Version 3 fixtures contain an empty 32-bit compatibility transition block, a 64-bit block, and an LF-delimited POSIX footer. Each type has its stated offset, DST flag and NUL-terminated abbreviation. Transition timestamps are seconds since the Unix epoch.
