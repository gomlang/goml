# Native reference test support

Consumer black-box tests use this package to load independent reference inputs and expected values, compare JSON trees, and call consumer protocols with a 120-second process timeout. Process operations return `Result`; test assertions identify failed reference operations. Test fixtures record their model, seed, case count, source revision, and SHA-256 in the adjacent `tests/data/README.md`.

Large fixtures share repeated subtrees using the documented `indexed-json-v2` format. Decoding preserves integer number tokens and does not round through floating point. Object comparison ignores field order. Expected values come from independent specifications, GNU/Git/reference implementations, or the former independent models, never from recorded GoML output.

`Screen` independently replays the terminal sequences emitted in the TUI and ANSI test corpus. It handles fragmented UTF-8/CSI/OSC, cursor positions, SGR colors/attributes, wide-cell overlap, combining marks, and the emoji ZWJ clusters used in these tests. Its controlled-corpus width rules cover CJK U+2E80–U+9FFF, emoji U+1F300–U+1FAFF, combining U+0300–U+036F and variation selectors. It is a test model, not a general Unicode terminal emulator; it deliberately has no dependency on the ANSI, TUI, terminal, or Unicode libraries being tested.

The native Linux PTY harness in the parent module allocates private `/dev/ptmx` terminals through the standard Linux descriptor APIs. Every child is reaped and every descriptor is closed on success or error. Successful scenarios compare exact termios and descriptor flags, terminal modes and expected output. Password checks strip CSI from the full output history, so cursor movement, per-character styling, and later erasure cannot hide leaked input. Failure tests repeatedly reject a missing child program and verify descriptor counts remain stable. Each wait has a deadline; the large-write case checks all 4 MiB of output while exercising backpressure.
