# D0 Go interface adapter acceptance

Status: D0 accepted for the documented module compilation path. Focused runtime checks and full CI pass. D1 and D2 are outside this acceptance record and remain incomplete.

| Requirement | Implementation and evidence |
| --- | --- |
| Preserve native Go interface identity | `tast/go_interface.gom` compares native method signatures and receiver identity. `hir/go_interface.gom` generates a wrapper with a private raw field and explicit `from_go`/`into_go` methods. The driver reader regression imports the raw interface from a separate package. |
| Keep Go interface and GoML dyn distinct | The wrapper implements the explicitly mapped trait; callers explicitly coerce that wrapper to dyn. The reader regression executes concrete and dyn calls against the same receiver, checking its Go call counter. |
| Require a complete method mapping | `ffi/interface_metadata.gom` consumes the completed Go method set. `tast/go_interface.gom` requires a one-to-one mapping and exact parameter/result representations. AST/TAST tests cover invalid/duplicate mappings and implicit conversion or result dropping. Driver tests reject an incomplete io.ReadCloser mapping and a missing Go method in required and off modes. |
| Preserve nil and typed-nil values | The driver regression wraps and unwraps both variants and checks native Go nil comparison. A typed-nil reader method is called using its original receiver semantics. |
| Reject constraint-only runtime interfaces | Go helper runtime type witnesses and completed metadata use the official Go type checker. `project_external_runtime_interfaces_reject_constraints` verifies ordinary runtime interfaces and rejects constraint-only interfaces in required/off modes, including cached repetitions. |
| Real io.Reader and multi-result/error behavior | `project_go_interface_adapter_preserves_reader_identity_and_partial_results` checks n=3 together with io.EOF, Go writes into an explicitly shared byte slice, retained receiver state and typed-nil method results. |
| Diagnose unsupported declarations before publication | `ffi_interface_adapter.gom` validates imported metadata and generated declaration/member collisions before package artifact publication. The negative driver regression covers seven invalid contracts with source labels and verifies absence of new interface/Core outputs. Source changes intentionally invalidate old cache outputs. |
| Preserve package artifacts and library reachability | The driver reader fixture crosses raw/api/main packages. `project_go_interface_adapter_survives_library_linking` exports a scalar/tuple function whose implementation uses the wrapper through dyn; an ordinary Go test invokes it repeatedly. Repeated required/off generation is byte-identical and retains portable api.gom origins. |
| Formatting and recoverable diagnostics | `go_interface_rejects_non_trait_and_nested_attachments` distinguishes parser rejection of method attributes from invalid top-level placement. `format_go_interface_mapping` checks valid output and idempotence while preserving attribute interiors verbatim. |
| Bootstrap and complete regressions | Full `/tmp/goml-interface-d0-ci-0906.log` completed with exit 0: 871 compiler tests, 139 driver tests, helper race checks, stage3 fixed-point artifact comparisons, extension compilation and extracted-release/LSP smoke. |
