## Frozen constraints

| Plan constraint | Inspected implementation and evidence |
| --- | --- |
| Preserve existing go_ffi syntax and wrapper behavior | `tast/ffi.gom::foreign_bridge_type` retains numeric, string/char, array, slice/channel and direct empty-marker representations. Existing pipeline/module fixtures and the complete compiler suite pass. Helper witnesses retain generic inference, fixed variadic arguments and discarded-result call statements. |
| Ordinary Go runtime and static linkage | Pointer and external types lower to native Go types. Callback and interface bridges use typed fields and method values retaining ordinary Go references. No FFI object-handle table, reflection dispatch, unsafe layout conversion, cgo ABI or plugin mechanism is introduced. Native imported packages retain their own requirements. |
| Official Go type rules | `tools/goml-go-meta` uses pinned x/tools v0.36.0 and go/packages/go/types. Build witnesses are Go AST nodes. It has no dependency on the separate experimental gomlgo parser. |
| Compiler responsibility boundaries | HIR constructs/resolves declarations; `tast/go_interface.gom` and `tast/ffi.gom` make type decisions from supplied metadata. Compiler command orchestration and `goml/project/ffi.gom` own processes and context. No host loading is added to the TAST environment. |
| Structured emission | GoLibrary wrappers, explicit method expressions, native generic instantiation, variadic expansion, callback methods and interface assertions have Go AST representation and printer/backend tests. Attributes do not carry arbitrary executable Go fragments. |
| Explicit value policies | `lib/std/ffi/ffi.gom` separates Ptr, Error, NonNilError, Outcome, String, Rune, RawSlice, RawMap and Func. Source/driver regressions reject implicit container, text, pointer, error and nullable conversions. |
| Runtime-only FFI | `tast::foreign_binding` rejects comptime foreign schemes. Imported callable and interface-bridge validators reject comptime capability and invalid metadata. The current compiler suite passes the source and artifact regressions. |
| Versioned source boundary | Interface JSON 30/value section 13 and Core JSON 28/value section 8 preserve structured metadata. Protocol v1 uses bounded structured messages with recoverable errors. No cross-Go-version binary ABI is promised. |
