# D1 trait-to-Go-interface acceptance audit

Status: accepted. Full CI passed with 895 compiler tests, 154 driver tests, helper race checks, stage3 fixed-point comparisons, extension compilation and extracted-release/LSP smoke.

| Plan requirement | Implementation and executable evidence |
| --- | --- |
| Complete native method set and receiver/signature checks | `tast/go_interface.gom::plan_go_interface_adapter` requires a concrete interface, one-to-one complete mapping, a Self receiver, non-generic instance methods and identical explicit bridge representations. It rejects private native methods and unsupported traits with recoverable errors. |
| Typed bridge and compile-time assertion | `go_backend/interface_bridge.gom::emit_interface_bridge` emits typed closure fields, ordinary Go methods and a blank-identifier native-interface assignment. `interface_bridge_forward` preserves zero results and unpacks multiple results. `go_interface_bridge_emission_satisfies_native_reader_and_preserves_results` compiles the resulting native reader; the empty-tuple regression checks effect preservation without an unused local. |
| Go retains a GoML implementation after return | `project_go_interface_bridge_retains_trait_state_and_partial_results` retains a reader through an explicit Go registration, runs GC, observes captured GoML state, shared buffer writes and the original EOF, then removes the registration. |
| Asynchronous, concurrent and reentrant calls | `project_go_interface_bridge_library_preserves_async_reentry_and_panic` exports InstallReader, transfers retained interfaces to a Go host, calls after GC on another goroutine, and tests eight independently owned readers. Registration is explicitly synchronized. A native hook reenters the same reader; state reflects the nested call. The host runs with `go test -race -count=1`. |
| Original panic and error identity | The same library host checks `io.EOF` by identity and recovers the fixture's original panic token on the same goroutine. The emitter does not introduce recover, a global FFI lock, reflection dispatch, unsafe conversion or an object-handle registry. |
| Unsupported or changed contracts | `project_go_interface_bridge_rejects_unsupported_trait_shapes` covers associated types, generic traits, missing receivers and generic methods, with source diagnostics and no panic. `project_go_interface_bridge_rejects_stale_and_private_method_sets` changes an already checked native interface and checks private methods. Both exercise required and off modes. |
| Artifacts, pruning and deterministic output | The library test repeats required/off exports, compares complete generated Go bytes and checks portable declaration origins and native assertions. `go_interface_bridge_imports_require_current_complete_metadata` reads interface and Core files, including private nested bridge uses, and rejects missing or inconsistent method metadata in both modes. |

The bridge holds ordinary typed callbacks that keep the same dyn object reachable. Native interfaces and GoML dyn values remain distinct; conversion is explicit through `ReaderAdapter::from_trait(value).into_go()`. Shared mutable user state retains ordinary synchronization obligations. The tests do not claim that unsynchronized mutation of one reader is race-free.
