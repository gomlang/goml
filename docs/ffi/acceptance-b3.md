## Source and artifact map requirements

Source-only dependency analysis checks dependency bodies and attaches inferred requirements before external schemes lose their declaration IDs. The regression covers two dependency packages, reverse file order, function values, nested closures, distinct owners with same-named methods and unsaved dependency overrides. All 66 query tests passed in `/tmp/goml-query-signature-suite.log`.

Opaque public structs retain a comparability summary without exporting private field names or types. Private raw-slice fields reject the key; private pointer-to-slice fields remain valid. The driver regression checks fresh/cached behavior and private-field edits (`/tmp/goml-opaque-key-test.log`). Two codec tests exercise rule roundtrips and invalid parameters/depth (`/tmp/goml-struct-comparability-codec.log`). Unknown hidden structure does not establish comparability.

Structs and enums retain the key requirements of contained maps, including private storage and aliases. Declaration summaries propagate with a recoverable 256-pass bound; applications substitute requirements without recursively expanding nominal layouts. All eight map driver regressions passed (`/tmp/goml-nominal-map-driver.log`). The expanded nominal regression covers aliases, enum payloads and mutually recursive pointer-linked declarations (`/tmp/goml-nominal-expanded-driver.log`). The query regression checks argument-expanding recursive applications (`/tmp/goml-nominal-recursive-query.log`).

Default trait methods retain inferred map requirements separately from declared method bounds. Only implementations using the default body must satisfy those requirements. Cross-package regressions pass for comparable pointer-bearing receivers, invalid slice-bearing receivers, explicit overrides, edits to default bodies and scalar/pointer/raw-slice associated types, with fresh/cached checks and valid execution (`/tmp/goml-default-associated-driver.log`, two passed). Implementation witnesses and method environments now retain the resolved canonical trait identity. Interface JSON is version 29; its binary value section is version 12. Core remains JSON 27 / binary value section 7.

Earlier standalone audits established the opaque, nominal and default-body source-check failures before these fixes. Their evidence and implementation history remain in `implementation-plan.md`; they are not current acceptance claims. Static generic associated-type consumers and strengthened blanket implementation methods were also audited (`/tmp/goml-trait-map-audit.log`). The final source review confirms that `validate_trait_impl` checks every selected default before publishing a checked package, with associated-type aliases installed during substitution. `coerce_to_dyn` requires a satisfying implementation and matching associated types; dyn conversion does not bypass the implementation check. Explicit method bodies retain the existing declared-contract validation.
